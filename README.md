# 16-BIT RISC PROCESSOR

## Project Overview
This project presents the design and implementation of a 16-bit RISC processor using Verilog HDL.

## Features
- 16-bit processor architecture
- Arithmetic and logical operations
- Register file
- Instruction memory
- Data memory
- Control unit
- Program counter
- ALU
- Simulation and FPGA implementation using Xilinx Vivado

## Tools Used
- Verilog/SystemVerilog HDL
- Xilinx Vivado 2018.2
